A small UIKit practice project for learning how to show alerts with `UIAlertController`, built around a simple sign-up form.

## ✨ Features

- Sign-up screen with **username**, **password** and **password again** fields (Storyboard + `@IBOutlet`)
- `Sign Up` button wired with an `@IBAction`
- Alert handling with `UIAlertController` and `UIAlertAction`

## 🛠️ Tech

- Swift, UIKit
- Storyboards / Interface Builder

## 🚀 Getting Started

```bash
git clone https://github.com/SemihSamandar/AlertProject.git
cd AlertProject
open AlertProject.xcodeproj
```

Pick a simulator in Xcode and press **⌘R** to run.

## 📁 Project Structure

```
AlertProject/
├── AppDelegate.swift
```
